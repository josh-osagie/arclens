## What you can do

<CardGrid stagger>
	<Card title="Analyze" icon="magnifier">
		Scan a React/TypeScript project and print node counts, relationships, external libraries, and optional architecture insights in the terminal.
	</Card>
	<Card title="Visualize" icon="seti:react">
		Open the bundled viewer to explore components, hooks, contexts, and utilities as an interactive dependency graph.
	</Card>
	<Card title="Watch" icon="approve-check">
		Re-analyze on file changes with `pnpm dev:watch` while the viewer auto-refreshes from `graph.json`.
	</Card>
	<Card title="Focus" icon="forward">
		Use `--focus` in the CLI or search and entry-point shortcuts in the viewer to trace how code connects.
	</Card>
</CardGrid>
